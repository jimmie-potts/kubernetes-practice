# Labs are interactive HTML on GitHub Pages

Lab documents are hand-authored HTML under `docs/labs/`, sharing one stylesheet and script in `docs/labs/assets/`, served publicly by GitHub Pages from the `docs/` folder and locally with `python3 -m http.server`. Interactivity is client-side only: per-step progress and quiz scores persist in the reader's browser, and live check buttons probe the tenant endpoints over HTTP (which requires the local copy; the https Pages site cannot fetch http endpoints). Pages cannot run kubectl, so cluster-state verification stays in the terminal. The markdown labs were retired rather than kept in parallel because two copies of one lab drift; git history preserves them. Chosen over a static-site generator because this repo does not need a build step.
